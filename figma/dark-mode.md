# Dark mode color roles

The dark theme is neutral-first. Green communicates brand and state; it is not
the default color of every surface.

| Role | Value | Usage |
| --- | --- | --- |
| Page | `#0B1211` | Browser background and empty space |
| Surface | `#141C1A` | Cards, header, footer, panels |
| Elevated | `#1A2421` | Sticky controls and elevated reading tools |
| Border | `#2A3834` | Quiet separation without bright outlines |
| Text | `#F1F5F3` | Primary text |
| Muted text | `#9EACA7` | Metadata and descriptions |
| Brand | `#7BC8AD` | Links, focus, active states |
| Brand muted | `#19352F` | Selected rows and source badges |
| Accent | `#DCB36B` | Verse markers and rare emphasis |
| Hero | `#102A25` | Session and next-prayer heroes |

Avoid pure black, pure white cards, green body copy, and gold paragraphs. Keep
Quran reading surfaces calm and visually separate from navigation.
